Sales and Customer Insights Dashboard

Project Overview
This project explores company sales and customer data to uncover insights that drive business growth and improve marketing performance. Using **SQL**, **Excel**, and **Power BI**, I developed an end-to-end data analytics solution — from data cleaning and transformation to creating an interactive dashboard that visualizes key performance metrics.

Objective
To identify top-performing products, sales trends, and customer behavior patterns that inform business strategy and help management make data-driven decisions.

Key Insights
- Top 10 products contributed to over 60% of total revenue.  
- The North and West regions consistently outperformed others in quarterly sales.  
- Returning customers generated 25% higher average order value than new customers.  
- Seasonal trends showed strong peaks in Q4, suggesting effective holiday campaigns.

Tools & Technologies
- SQL – Data extraction and transformation  
- Power BI – Dashboard creation and analysis  
- Excel – Data preparation and validation  

Skills Applied
`SQL`, `Power BI`, `Excel`, `Data Cleaning`, `Data Visualization`, `Data Analysis`, `Dashboard Design`, `DAX`, `Business Intelligence`

Dashboard Highlights
The Power BI dashboard includes:
- Sales Overview by Region and Category
- Revenue Trends and Forecasts
- Top Customers and Profitability
- Customer Demographics and Retention Analysis
